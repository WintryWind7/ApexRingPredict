# 关于毒圈预测的初步理解

## 项目目标

基于深度学习预测 Apex Legends 游戏中的毒圈位置，类似 AlphaGo 展示多个高概率落子点。

## 核心思路

### 问题定义

- **输入**：前 N 级毒圈中心坐标 (x, y)
- **输出**：后续级别的多个可能位置及其概率分布
- **约束**：每级毒圈半径固定，只需预测圆心坐标

### 支持的预测模式

- 输入 1 级 → 预测 2、3、4 级
- 输入 1、2 级 → 预测 3、4 级
- 输入 1、2、3 级 → 预测 4 级

## 技术方案

### 模型设计

**输入层**
- 前 N 级毒圈坐标（归一化后的 x, y 坐标）
- 输入维度：N × 2

**输出层**
- 地图网格的概率分布（热力图）
- 输出维度：H × W（如 100×100）
- 每个网格点表示该位置作为毒圈中心的概率

**网络架构**
- 待研究确定

### 后处理流程

**NMS 变体（概率聚合）**

1. **寻找局部峰值**
   - 在概率图上找到所有局部极大值点
   
2. **区域概率聚合**
   - 以每个峰值点为中心
   - 计算周围一定半径内所有点的概率总和
   - 示例：峰值点概率 1.5%，周围区域总和可能达到 34%
   
3. **Top-K 选择**
   - 选出概率总和最高的 4-5 个区域
   - 每个区域用峰值点作为代表坐标
   
4. **结果展示**
   - 在地图上标注 Top-K 个预测位置
   - 显示每个位置的聚合概率

### 交互方式

- 用户在地图上点击放置前 N 级毒圈位置
- 实时显示后续级别的 Top 5 预测位置及概率

## 待确定参数

1. **地图坐标范围**
   - Apex 地图的实际坐标系统

2. **输出网格精度**
   - 概率图分辨率（如 100×100 或 200×200）
   - 影响预测精度和计算量

3. **NMS 聚合半径**
   - 概率聚合时的邻域范围
   - 影响最终展示的区域大小

4. **数据集规模**
   - 需要收集的比赛场次数量
   - 数据来源和采集方式

## 技术优势

1. **轻量化**：只使用坐标数据，不涉及图像处理
2. **可解释性**：输出概率分布，直观展示预测结果
3. **灵活性**：支持多种输入模式（1→234、12→34、123→4）
4. **实用性**：类似 AlphaGo 的多候选展示，符合实际使用场景

   - 各方案的优劣权衡

2. **输出层设计**
   - 如何同时输出多个级别的预测（如输入1级，输出234级）？
   - 是否需要分别输出 3 个概率图？

3. **数据格式设计**
   - 训练数据的存储格式
   - 是否需要记录地图信息
   - 数据归一化方案
